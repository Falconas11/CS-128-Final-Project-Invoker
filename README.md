Project Introduction: As a player of Invoker in Dota2, I find the hero especially hard to practice, since it has the keys Q, W, and E for three different elements and R to invoke a skill based on the current combination based on the current three elements, and has 10 skills in total. Therefore, I would like to design a mini game that can help simulate the skill invoking process, improving Invoker players' proficiency and reaction when invoking skills. This will be an interactive mini game that replicates the skill invoking process in Dota2.

Technical Overview: First implement the basic logic of the skill invoking process and create an interactive version in the terminal. Then implement the same logic with egui package and form an individual window with animated skills instead of words. Finally add interactive elements to it, such as reaction time test and APM count.

Checkpoint 1: basic logic of key inputs, combining skills, invoking skills into the correct slots.

Checkpoint 2: add dialogue for successful/failed invocation. Form a new version with pictures of skills in an individual window instead of a terminal.

Final: time permitting, add more functionalities to it, including timer, random skill reaction test, and potentially sound.

Possible Challenges: I only know the basics of Rust, and have no idea about egui, eframe and key inputs. I also haven't worked with UI in other languages. I will have to tackle these obstacles.
